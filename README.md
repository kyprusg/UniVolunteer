# UniVolunteer — Цифровая платформа студенческих волонтерских инициатив

Веб-приложение для автоматизации записи на университетские социальные акции, верификации волонтерских часов и управления портфолио активиста. Проект выполнен в рамках лабораторных работ №1–2 по курсу «Проектная деятельность» (симуляция полного цикла Scrum).

## Стек технологий
* **Фронтенд:** React 19, TypeScript, Vite, Tailwind CSS.
* **Управление состоянием:** Zustand с сохранением в `localStorage`.
* **Компоненты и анимация:** Lucide React, Framer Motion, Canvas Confetti.
* **Тестирование:** Встроенный браузерный раннер юнит-тестов бизнес-логики (7/7 пройденных тестов).

## Архитектура проекта
* `src/services/VolunteerScoringService.ts` — расчет часов с учетом коэффициентов сфер деятельности (1.0x–1.5x), лидерских надбавок (+2 ч) и защита от превышения лимита мест (Mutex-блокировка).
* `src/components/CatalogView.tsx` — каталог акций с фильтрацией, поиском и 4 состояниями кнопок (активна, отправлено, мест нет, ошибка)[cite: 30, 46].
* `src/components/ProfileView.tsx` — профиль студента с отображением 42 волонтерских часов, геймификацией и списком заявок[cite: 31, 46].
* `src/components/CuratorDashboard.tsx` — панель организатора для подтверждения заявок и создания новых инициатив[cite: 33, 46].
* `src/components/TestRunner.tsx` — интерактивный модуль прогона тестов ядра платформы[cite: 32, 46].
